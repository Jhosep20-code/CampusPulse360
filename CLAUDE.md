# CampusPulse 360 

## Objetivo 
Construir ahora una plataforma de gemelo digital universitario inteligente, funcional y desplegada publicamente. 

## Fuente de requisitos 
Leer docs/requisitos/RUBRICA_PROYECTO_FINAL.pdf antes de planificar. 
Cumplir los cinco ejes: RPA, CI/CD y Docker, IA generativa, AR/VR e IoT. 

## Stack propuesto 
React, TypeScript, Tailwind, Three.js, Cloudflare Workers, D1, Workers AI, Docker y GitHub Actions. 

## Identidad visual 
Fondo #080F1D, paneles #17243A, azul #2962FF, cian #22D3D6 y dorado #F0B95B. 
Diseno tecnologico premium, responsive y accesible. 

## Reglas obligatorias 
- Presupuesto adicional: S/ 0.00. 
- No activar facturacion ni comprar creditos API. 
- No modificar archivos fuera de este proyecto. 
- No inventar pruebas, mediciones ni resultados. 
- Verificar cada modulo antes de declararlo terminado. 
- Diferenciar simulaciones de mediciones reales. 
- Registrar decisiones tecnicas y riesgos. 
- Usar agentes especializados solo cuando aporten valor. 

## Flujo de trabajo 
Analizar requisitos, disenar, implementar, probar, desplegar y documentar.
