# Auditoria de rubrica

Fuente obligatoria:
docs/requisitos/RUBRICA_PROYECTO_FINAL.pdf

Comprobar los cinco ejes:
1. Automatizacion RPA.
2. CI/CD y contenedores Docker.
3. IA generativa, API y Prompt Engineering.
4. Realidad aumentada o virtual funcional.
5. Recepcion y visualizacion IoT.

Evaluar los nueve criterios y sus puntajes.
Comprobar entregables, video e informe tecnico.

Para cada requisito indicar:
- Cumplido, parcial o pendiente.
- Evidencia verificable.
- Riesgo de perder puntos.
- Accion correctiva.

No confundir modelos compatibles con OpenAI con
el uso de la API oficial exigida en la rubrica.

No inventar resultados ni evidencias.
