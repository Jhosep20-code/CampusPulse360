# Verificacion de modulos

Para cada funcionalidad:

1. Leer requisitos y criterios de aceptacion.
2. Inspeccionar el codigo implementado.
3. Ejecutar las pruebas disponibles.
4. Comprobar integraciones y manejo de errores.
5. Revisar seguridad y rendimiento.
6. Comprobar funcionamiento multidispositivo.
7. Registrar resultados y limitaciones.

Clasificar las pruebas:
- Aprobada.
- Fallida.
- No ejecutada.
- Bloqueada.

Nunca declarar una funcionalidad terminada
sin evidencia verificable.

No ejecutar servicios de pago.
No modificar archivos fuera del proyecto.
